# 異世界転生した鍛冶屋の話

## あらすじ

六十二年の生涯を刀一筋に捧げた刀匠・相沢寅次郎は、工房で槌を振るったまま息を引き取る。
気づけば彼は、剣と魔法が当たり前に存在する異世界で、身寄りのない少年「ノア」として目を覚ましていた。
前世の記憶と、五十年以上かけて磨き上げた鍛冶の技術だけを引き継いだまま。

貧しい孤児院で育つノアは、廃材の鉄くずを打つことだけを心の支えに生きていくが、
その腕前は、やがて村の鍛冶屋の目に留まることになる――。

第一話では、寅次郎の死から異世界への転生、そして鍛冶屋ガルドとの出会いまでを描く。

## 登場人物

- **ノア(前世:相沢寅次郎)**
  前世は日本の刀匠。享年六十二。頑固で無口だが、鉄と向き合っているときだけは饒舌になる職人気質。
  転生後は身寄りのない六歳の少年。前世の記憶と技術をすべて保持している。

- **リディエル**
  ノアを異世界に導いた声だけの存在。おそらく神に近い何か。多くを語らず、事務的な口調で転生の理由を告げる。

- **ガルド・ヘイスト**
  辺境の村「ミレド村」で鍛冶屋を営む中年の男。腕はいいが客が少なく、経営は火の車。無骨だが面倒見はよい。

## 世界観・用語

- **舞台**: ヴァルシア王国の辺境にある小さな村「ミレド村」。魔物や魔法が存在する剣と魔法の世界。
- **孤児院**: ミレド村の外れにある教会付属の施設。戦争や魔物被害で親を失った子供たちが暮らす。
- **鍛冶**: この世界の鍛冶技術は前世の日本より遥かに未発達で、量産品の質は低い。ノアの技術は規格外として扱われる。
