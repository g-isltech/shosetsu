# shosetsu

Claude Code を活用して小説を執筆・管理するプロジェクトです。
GitHub の Web コンソール上でそのまま読めることを前提にしたディレクトリ構成・Markdown 形式で作品を管理します。

## ディレクトリ構成

```
<カテゴリ名>/
  <作品名>/
    README.md      # あらすじ・登場人物・設定などの概要
    01_第一話.md
    02_第二話.md
    ...
```

- ルート直下は「カテゴリ」ごとのディレクトリです(例: `ファンタジー/`, `恋愛/`, `SF/` など)。
- カテゴリディレクトリの中に、作品ごとのディレクトリを作成します。
- 作品ディレクトリの中には、話数ごとに Markdown ファイルを分けて格納します。
  ファイル名は `01_話タイトル.md` のように2桁の連番 + タイトルを付け、GitHub 上でソートしたときに話順に並ぶようにします。
- 作品ディレクトリ直下の `README.md` には、あらすじ・登場人物・世界観設定など、その作品の概要をまとめます。

## GitHub での閲覧方法

1. リポジトリのトップページからカテゴリディレクトリを開く
2. 読みたい作品のディレクトリを開く
3. 作品ディレクトリの `README.md` であらすじを確認できる
4. 話数ファイル(`01_〜.md` など)を開くと本文がそのまま読める

Markdown ファイルは GitHub の Web コンソール上でそのまま整形表示されるため、追加のビューアなどは不要です。

## 執筆時のルール
